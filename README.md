# Маяк — настольный клиент

[Скачать Маяк 0.1.0-alpha.84 для Windows, Linux и Arch](https://github.com/MerryGrim/mayak-releases/releases/tag/v0.1.0-alpha.84). Сайт: [mayakchat.su](https://mayakchat.su).

Глобальные горячие клавиши работают при свёрнутом окне: Ctrl+Shift+M — микрофон, Ctrl+Shift+D — звук. Изменить сочетания можно в «Настройках приложения» через меню или трей клиента.

С alpha.84 клиент проверяет обновления из этого репозитория: подпись манифеста Ed25519, размер и SHA-256 пакета. Скачивание может идти в фоне. Установка выполняется по нажатию и недоступна во время разговора. Для перехода с alpha.66 новый клиент нужно один раз установить вручную.

Windows — установщик x64; Debian/Ubuntu — DEB x64; Arch Linux — пакет pacman x86_64; остальные Linux — архив x64. Системные пакеты Linux устанавливаются через polkit; архив заменяется вручную.

Выпуски alpha предназначены для тестирования. Сертификат Windows Authenticode пока не настроен; Smart App Control может блокировать установщик. Полный автоматический перезапуск Windows пока не подтверждён. Новая версия Arch проверена в контейнере; проверка на физическом компьютере остаётся открытой.

Этот репозиторий содержит готовые выпуски и описание установки. Пользовательские данные и закрытые ключи сюда не публикуются.
