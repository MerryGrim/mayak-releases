# Маяк — настольный клиент

[Скачать Маяк 0.1.0-alpha.85 для Windows, Linux и Arch](https://github.com/MerryGrim/mayak-releases/releases/tag/v0.1.0-alpha.85). Сайт: [mayakchat.su](https://mayakchat.su).

Windows переходит на Inno Setup. Для новой установки и первого перехода с прежнего клиента скачайте **Mayak-Inno-Setup-0.1.0-alpha.85-x64.exe**, закройте Маяк и запустите установщик вручную. Миграция рассчитана на сохранение каталога установки и профиля. Реальный переход NSIS→Inno на текущем Windows пока не проверен.

Глобальные горячие клавиши работают при свёрнутом окне: Ctrl+Shift+M — микрофон, Ctrl+Shift+D — звук. Изменить сочетания можно в «Настройках приложения» через меню или трей клиента.

Обновления проверяются по закреплённому ключу Ed25519, размеру и SHA-256 пакета. Alpha.85 использует подписанный **mayak-update-v2.json** с Inno; для alpha.84 сохранены **mayak-update.json** прежнего формата и настоящий NSIS-пакет. Скачивание может идти в фоне; активный разговор блокирует установку при нажатии кнопки. Первый автоматический переход из alpha.84 и полный автоматический перезапуск пока не подтверждены; рекомендуем ручной переход на Inno.

Debian/Ubuntu — DEB x64; Arch Linux — пакет pacman x86_64; остальные Linux — архив x64. Системные пакеты Linux устанавливаются через polkit; архив заменяется вручную. Рецепт Arch доступен в ZIP выпуска; в AUR он ещё не опубликован.

Выпуски alpha предназначены для тестирования. Сертификат Windows Authenticode пока отсутствует; политика Windows может блокировать установщик. Пакет Arch проверен установкой и аудитом в отдельном контейнере; проверка на физическом компьютере остаётся открытой.

Этот репозиторий содержит готовые выпуски и описание установки. Пользовательские данные и закрытые ключи сюда не публикуются.
