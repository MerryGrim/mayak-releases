# Маяк — настольный клиент

Официальные установщики для Windows x64, Debian/Ubuntu x64 и Arch Linux x86_64 находятся в [разделе Releases](https://github.com/MerryGrim/mayak-releases/releases).

Сайт: [mayakchat.su](https://mayakchat.su).

Выпуски alpha предназначены для тестирования. Начиная со следующего выпуска с поддержкой обновления клиент проверяет подписанный манифест и контрольную сумму перед установкой. Обновления скачиваются с этого репозитория; перезапуск откладывается во время разговора.

Этот репозиторий содержит готовые выпуски и описание установки. Пользовательские данные и закрытые ключи сюда не публикуются.
