# Маяк — настольный клиент

[Скачать Маяк 0.1.0-alpha.86 для Windows, Linux и Arch](https://github.com/MerryGrim/mayak-releases/releases/tag/v0.1.0-alpha.86). Сайт: [mayakchat.su](https://mayakchat.su).

Windows снова использует обычный установщик **Nullsoft NSIS**. Скачайте **Mayak-Setup-0.1.0-alpha.86-x64.exe**, закройте Маяк и запустите установщик вручную. Если Inno alpha.85 уже установлен, сначала удалите его обычным деинсталлятором; данные профиля хранятся отдельно. Ctrl+R обновляет веб-интерфейс.

Глобальные горячие клавиши работают при свёрнутом окне: Ctrl+Shift+M — микрофон, Ctrl+Shift+D — звук. Изменить сочетания можно в «Настройках приложения» через меню или трей клиента.

Alpha.86 использует подписанный **mayak-update.json** со штатным NSIS и тремя Linux-пакетами. Проверяются закреплённый ключ Ed25519, размер и SHA-256 пакета. Скачивание может идти в фоне; активный разговор блокирует начало установки. Новый загрузчик передаёт NSIS-обновление вне группы процессов закрывающегося клиента. Папки с пробелами поддерживаются. Для первого перехода со старого клиента используйте ручную установку; замороженный Inno-updater alpha.85 не принимает выпуск без v2-манифеста.

Debian/Ubuntu — DEB x64; Arch Linux — пакет pacman x86_64; остальные Linux — архив x64. Системные пакеты Linux устанавливаются через polkit; архив заменяется вручную. Рецепт Arch доступен в ZIP выпуска; в AUR он ещё не опубликован.

Выпуски alpha предназначены для тестирования. Реальная установка и автоматический перезапуск alpha.86 на Windows, а также проверка на физическом Arch-компьютере пока не выполнены. Подпись Windows Authenticode отсутствует.

Старые выпуски alpha.84 и alpha.85 удалены с GitHub; локальные пакеты и исходные срезы сохранены. Этот репозиторий содержит готовые выпуски и описание установки. Пользовательские данные и закрытые ключи сюда не публикуются.
